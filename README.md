# Blue-Renaissance
A web project promoting ocean conservation and awareness of Sustainable Development Goal 14 — Life Below Water.
Blue Renaissance explores the importance of protecting marine ecosystems, with a particular focus on coral reefs. It combines educational content and an image gallery to help visitors understand threats to ocean life and discover practical ways to contribute to conservation.
About the project
Created as a university Web Design and Development coursework project, Blue Renaissance applies HTML, CSS, and JavaScript to present environmental information through a visually engaging website.
The project connects web development practice with a meaningful topic: protecting the oceans and the ecosystems that depend on them.
Features
- Coral reef content: an introduction to coral reefs, their importance, key threats, conservation success stories, and ways to get involved.
- Student actions: practical ideas that encourage students to support marine conservation.
- Image gallery: a card-based gallery with expanded image views.
- Page navigation: section links and a "Go to top" control to help visitors explore longer content pages.
- Responsive layouts: styling for presenting content and images across different screen sizes.
Technologies
Technology	Purpose
HTML5	Page structure, navigation, and educational content
CSS3	Layout, styling, gallery presentation, and responsive design
JavaScript	Interactive gallery behaviour and page interactions


Getting started
Requirements
- A modern web browser.
- A local copy of the project files.
- Optionally, Visual Studio Code with the Live Server extension.
Run locally
1. Download the repository files or clone the repository using your GitHub access.
2. Open the project folder in Visual Studio Code.
3. Find the HTML file that serves as the website's home page.
4. Open it with Live Server, or open the HTML file directly in your browser.
5. Use the website navigation to explore the available pages.
Keep the project folders together so that relative paths to stylesheets, scripts, and images remain intact.
Project goals
- Raise awareness of ocean conservation and SDG 14.
- Explain why coral reefs matter and the threats they face.
- Encourage practical conservation actions.
- Develop skills in semantic HTML, CSS layouts, responsive design, and JavaScript interactions.
Development focus
The coursework includes attention to page structure, image presentation, navigation, and HTML/CSS validation. Future improvements can include broader accessibility checks, performance optimisation, and more educational content.
